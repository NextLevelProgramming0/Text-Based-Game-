# Text-Based-Game- My first completed programming project(Python)

The Project purpose was to create a Text Based Game that would allow a user to input commands to move around a map gathering the necessary items to pass elementary school.
I did a good job creating a strong foundation for the project with Psuedocode, flowcharts, and easily readable code.

I could have enhanced my code by using functions.  It would have made the program more organized.

The challenge I ran into when writing this code was how to connect the user input with the various rooms the user would be travelling through without errors.
I overcame this obstacle by doing further research into using while loops and updating variables throughout the loop based on user input. I found many useful websites that are able to teach you further coding skills.

The knowledge that I gained for using loops and creating/updating variables has been and will continue to be useful as I create more programs.
I could have made the program more maintainable by using more functions or classes within it.

I made my program more readable by using comments to describe the purpose of each part of the code.
I made this program adaptable by making it extremely flexible.  As long as all of a certain variable is adjusted this program can be changed for different purposes.
